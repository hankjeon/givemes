# 연간 업무 실적 평가 프로그램 요구사항

## 목적

미리 정해진 등수별 목표 점수에 맞춰 각 팀원의 업무별 평가 결과를 자동으로 산정한다.

## 확정된 규칙

- 한 사람은 1~10개 사업에 참여한다. 사업별 참여 비중은 미리 정해져 있으며, 사람별 합계는 100%다.
- 각 사람이 참여하는 사업마다 서로 다른 업무가 4개 있다. 업무 가중치는 10%, 20%, 30%, 40%이며 합계는 100%다.
- **사업 점수**는 각 업무 점수에 해당 업무 가중치를 곱해 합산한 값이다.
- **개인 최종 점수**는 각 사업 점수에 해당 사업의 참여 비중을 곱해 합산한 값이다.
- **개인 목표 점수**는 평가 인원수에 해당하는 목표 점수표에서 그 사람의 등수로 조회한다. 등수는 사용자가 직접 입력하며, 프로그램이 순위를 정하지 않는다.
- 목표 평균과 표준편차는 별도로 입력하지 않는다. 팀 평균과 표준편차를 계산할 때는 평가 대상자별 최종 점수를 하나씩 사용한다.

## YAML 입력 형식

파일 앞부분에 인원수별 목표 점수표를 둔다. 점수 목록은 1등부터 순서대로 적고, `사람` 아래에는 이름을 키로 사용해 각 사람의 등수와 사업별 참여 비중을 적는다. 사업도 사업명을 키로 사용한다.

```yaml
목표점수표:
  2: [90, 80]
  3: [90, 85, 80]

사람:
  김예시:
    등수: 1
    사업:
      차세대 시스템 구축: 60
      데이터 품질 개선: 40
  이예시:
    등수: 2
    사업:
      차세대 시스템 구축: 100
```

- 예시의 평가 인원은 2명이므로 `2: [90, 80]`을 사용한다. 참여 비중의 `60`은 60%를 뜻한다.
- 사람과 사업에 별도 ID를 두지 않는다. 동명이인은 사용자가 `김예시1`, `김예시2`처럼 구분한다. 이름 끝 숫자는 등수가 아니다.
- 사업명에 공백을 쓸 수 있다. `: `나 ` #`처럼 YAML에서 특별한 의미가 있는 부분이 들어간 이름은 따옴표로 감싼다.
- 업무명과 업무 가중치는 입력하지 않는다. 프로그램은 사업마다 고정된 `업무10`, `업무20`, `업무30`, `업무40`을 사용하고, 결과도 이 이름으로 구분한다.

## 입력 검증

- 사람 이름 중복, 같은 사람의 사업 참여 비중 합계가 100%가 아닌 경우, 등수 중복을 오류로 처리한다. 오류가 있으면 점수 계산을 시작하지 않고 문제가 된 이름과 값을 알린다.
- 사람 이름 중복은 YAML을 읽는 단계에서 확인한다. 같은 키가 조용히 덮어써지면 안 된다.
- 추가 검사 제안: 같은 사람 아래 사업명 중복, 등수 범위(1~N), 해당 인원수의 목표 점수표 누락 또는 점수 개수 불일치.

## 점수 산정 기준

- **필수 조건:** 산출된 개인 최종 점수는 입력 등수에 따라 `1등 > 2등 > … > N등`이어야 한다. 동점이나 순위 역전이 있는 조합은 유효한 결과로 인정하지 않는다.
- **최적화 목표:** 순위를 지키는 조합 중 개인별 절대 오차(`|산출 최종 점수 − 목표 점수|`)의 최댓값을 최소화한다. 목표 점수와 소수점까지 일치할 필요는 없다.

## 결과 화면

- 왼쪽에는 사람 목록을 입력 등수순으로 표시하고, 이름 옆에 산출 최종 점수를 보여준다. 산출 점수를 기준으로 등수를 다시 매기지 않는다.
- 사람을 선택하면 오른쪽에 사업별 업무 점수 표를 표시한다. 한 행은 한 사업이며, 업무 열은 `업무40`, `업무30`, `업무20`, `업무10` 순서다.
- 팀 요약에는 모든 평가 대상자의 **산출 최종 점수**로 계산한 평균과 표준편차를 표시한다.
- 화면 구성 제안: 사업명 옆에 참여 비중을 표시하고, 상세 화면 상단에 개인 목표 점수와 산출 점수를 나란히 표시한다. 등급제로 결정되면 각 업무 칸에 등급과 환산 점수를 함께 표시하는 방안을 검토한다.

## 미결 사항

- **우선 확인:** 업무별 평가가 점수 직접 부여 방식인지, S·A·B·C 같은 등급을 정해 점수로 환산하는 방식인지 확인한다. 등급별 환산 점수는 아직 정하지 않았다.
- 최대 개인 오차가 같은 조합이 여러 개면 어떤 기준으로 선택하는가? 점수 범위·단위와 반올림은 어떻게 정하는가?
- 허용된 점수나 등급으로 입력 등수 순서를 지키는 조합이 없다면 화면에 어떻게 안내하는가?
- 결과에 표시할 표준편차는 모집단과 표본 중 어느 방식으로 계산하는가?
