# 세션 인수인계

## 현재 상태

- 채점 요구사항을 논의 중이다. 프로그램 구현은 시작하지 않았다.
- YAML에 인원수별 목표 점수표와 사람별 등수·사업 참여 비중을 담기로 했다. 입력 예시와 필수 오류 검사는 [요구사항 문서](requirements.md)에 정리했다.
- 산출 점수는 입력 등수 순서를 반드시 지켜야 하며, 유효한 조합 중 최대 개인 오차가 가장 작은 조합을 우선한다. 결과는 등수순 사람 목록과 사업별 업무 표로 표시하고, 팀 평균과 표준편차도 표시한다.

## 다음에 이어갈 질문

**실제 평가 양식에서는 업무에 점수를 직접 부여하는가, 아니면 S·A·B·C 같은 등급을 부여한 뒤 점수로 환산하는가?** 등급제라면 환산표를 확인한다. 목표 점수와의 정확한 일치는 필요 없지만, 입력 등수 순서를 지키는 조합이 없을 때의 안내 방식은 아직 정하지 않았다.

답을 확인한 뒤 요구사항 문서를 갱신한다. 미결 기준은 임의로 확정하지 않으며, 논의에 대한 동의를 구현 승인으로 해석하지 않는다.
