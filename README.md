# givemes

평가 대상 인원 수와 등수로 목표 점수를 조회하고, 모든 사업에 공통으로 적용할 업무별 등급과 배점을 출력하는 터미널 프로그램입니다.

Python 3.12 이상에서 저장소 루트의 `src/givemes.py`를 바로 실행할 수 있습니다.

```sh
python src/givemes.py -n 10 -r 1
python src/givemes.py -n 10
```

명령 형식은 `givemes -n <N> [-r <R>]`입니다. `-n`은 필수이며 2~15명을 지원합니다. `-r`에는 1부터 `-n`까지의 등수를 지정할 수 있습니다. 생략하면 1등부터 마지막 등수까지 모두 출력합니다.

```text
| 등수 | 점수 | 업무40  | 업무30  | 업무20  | 업무10  |
|------|------|---------|---------|---------|---------|
| 1등  | 98   | S / 100 | S / 100 | A / 90  | S / 100 |
```

## 배점 규칙

- 업무40, 업무30, 업무20, 업무10의 가중치는 각각 40%, 30%, 20%, 10%다.
- 업무별 배점은 S=100, A=90, B=80, C=70이다.
- 네 업무의 가중합이 내장 목표 점수와 정확히 일치하는 조합 중에서 업무40에 C를 사용하지 않고 A 개수가 가장 많은 조합을 선택한다. A 개수가 같으면 업무40, 업무30, 업무20, 업무10 순으로 높은 배점을 우선한다.
